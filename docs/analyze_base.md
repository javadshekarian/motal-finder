# BASE Signal Analysis – Stability and Repeatability

## Overview

The `analyze_base.py` script analyzes the recorded baseline signal (`BASE.bin`) under no-metal conditions.

Each waveform contains 16 ADC samples, and the analysis groups waveforms by their position within a 13-wave repetition cycle.

Grouping every 13 waveforms allows measurements taken at equivalent positions in the repeating signal pattern to be compared, rather than mixing different waveform phases.

---

## Statistical Measurements

For each sample position within each group, the following statistical values are calculated:

| Statistical value | Description |
|---|---|
| **Mean** | Average ADC reading across all waveforms belonging to the same group. |
| **StdDev** | Standard deviation, indicating how much the readings fluctuate around their mean. |
| **Min** | Minimum recorded ADC value. |
| **Max** | Maximum recorded ADC value. |

---

## Observations

The results show strong measurement repeatability under baseline conditions:

- Most sample positions have a standard deviation below 1 ADC count.
- Sample 4 has a slightly higher standard deviation, approximately 0.5–1.05 ADC counts across the groups.
- Samples 7–16 generally show standard deviations below 0.75 ADC counts.
- The minimum and maximum values are also tightly distributed, with most readings varying by only a few ADC counts.
- Samples 1, 2, and 6 consistently return zero.
- Sample 3 consistently returns 1023, indicating that the ADC reading is at its maximum measurable value for this input.

---

## Conclusion

The baseline measurements demonstrate a high degree of repeatability. The low standard deviations indicate that the ADC readings remain stable when equivalent positions in the repeating waveform pattern are compared.

This provides a consistent baseline dataset for subsequent signal processing and metal-detection experiments. Changes in the measured waveform can later be evaluated against this baseline to identify deviations potentially caused by nearby metallic objects.

**Note:** Sample 3 is saturated at the ADC's maximum value (1023), so it does not provide useful voltage-resolution information in its current state. Samples that consistently return zero should also be treated as inactive measurement positions.
